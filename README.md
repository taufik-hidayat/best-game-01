**LUMENHOLD — Defend the Last Lighthouse.** A tower-defense game written from scratch in plain canvas: shadow wisps, beetles, sparks and the Gloom Moth march a winding road toward the last lighthouse, and you stop them with Ember Spires, Frost Lanterns and Prism Cannons built on the grass plots. Ten waves, a lumen economy, upgrades, synthesized sound, and a win screen when the dawn breaks.

## Play it

```sh
node serve.ts
# open http://localhost:8080
```

Mouse builds towers on the plots; `1/2/3` pick a tower, `Space` sends a wave, `P` pauses, `F` toggles fast-forward, `M` mutes, `U` upgrades and `X` sells the selected tower.
